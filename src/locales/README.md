# Language coverage

English, Hindi and Santali contain the same 132 UI keys.

Training content is delivered by the FastAPI backend. The frontend includes `trainingTranslations.json` as the translation source map for training strings; backend translation rows should be seeded from that map before deployment so lessons, drills and assessments display in the selected language.

Safety note: this translated content is for the prototype and should be reviewed by a qualified Hindi/Santali language reviewer and competent safety professional before statutory/workplace use.
